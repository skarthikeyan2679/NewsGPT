# NewsGPT 

NewsGPT is an AI-powered personalized technology news briefing platform. It helps users discover relevant technology news, save articles, select interests, and preview a personalized email digest.

## Day 1 Progress

Completed the complete frontend UI using React and Vite.

### Features implemented

- Modern responsive SaaS dashboard
- Persistent desktop sidebar and mobile navigation drawer
- Overview dashboard with briefing status and metrics
- Latest News Feed with:
  - Search
  - Category filtering
  - Sorting
  - Refresh loading state
- Article detail page
- Save and remove articles
- Saved Articles page with empty state
- Interest selection page
- Email Digest settings and realistic preview
- Settings page
- Toast success messages
- Mock news data with 15+ technology articles
- Responsive desktop and mobile layouts

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM
- Lucide React Icons
